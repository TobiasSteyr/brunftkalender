# Brunftkalender

Statische PWA für Herdenmanagement: Brunst, Besamung, Trächtigkeit und Kalbung.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

## Dateien
- `index.html` – App
- `manifest.webmanifest` – PWA-Metadaten
- `sw.js` – Offline-Cache
- `icon.svg` – App-Icon

## Datenschutz
Tierdaten werden aktuell lokal im jeweiligen Browser gespeichert. GitHub Pages hostet nur den App-Code. Der lokale PIN-Schutz ist keine serverseitige Authentifizierung.
